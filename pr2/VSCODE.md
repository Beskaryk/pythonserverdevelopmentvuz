# Запуск из VS Code

Открой в VS Code именно корень репозитория.

1. Нажми `Ctrl+Shift+P` и выполни `Python: Create Environment`.
2. Выбери `Venv`, установленный Python и файл `pr2/requirements.txt`.
3. Нажми `Ctrl+Shift+P`, выбери `Tasks: Run Task` и нужный этап.
4. Выполни `PR2: 0. Установить зависимости` после переключения этапа.
5. Открой `Run and Debug` сочетанием `Ctrl+Shift+D` и выбери запуск этапа.

Сервер останавливается кнопкой Stop или сочетанием `Ctrl+C` в терминале.
Тесты также доступны на панели Testing и через задачу `PR2: Тесты`.
